# Roadmap

## Phase 1: CLI MVP

- URL to desktop app.
- Config file.
- Icons.
- Window settings.
- Build command.

## Phase 2: Desktop Features

- Auto updater.
- System tray.
- CSS injection.
- JavaScript injection.
- App templates.

## Phase 3: Studio UI

- Visual project editor.
- One-click packaging.
- Template browser.
- Local build status.

## Phase 4: Enterprise and Kiosk

- MSI builder.
- PKG builder.
- Remote config.
- Fleet deployment.
- Fullscreen lock.
- Auto reload.
- Network monitor.
- Offline fallback page.
- Health checks.
